# beat-FFF
the FFF community had it coming.

## How to Use:

ctrl + 2 	=> run stage 2 - 1 script

alt  + 2 	=> run stage 2 - 2 script

ctrl + 3 	=> run stage 3 - 1 script

alt  + 3 	=> run stage 3 - 2 script

ctrl + 4 	=> run stage 4 - 1 script

alt  + 4 	=> run stage 4 - 2 script

ctrl + 5 	=> run stage 4 - 1 script using $100 bet

alt  + 5 	=> run stage 4 - 2 script using $100 bet"

### Stages?

Each opponent is a stage and every stage has 2 rounds.

For example:

If the pattern is only 1-2-1 then you are on stage 2.

- ctrl + 2 => runs the stage 2 - 1 script.
- alt + 2 => runs the stage 2 - 2 script.

"2 - 1" would be stage two round one.

### Max Bet Hotkey?

I created a special hotkey for betting $100 dollars (max bet) on the final character. Allegedly, betting the highest amount changes the pattern, but I didn't really notice this in testing.
I left it in just incase.

Have fun.
